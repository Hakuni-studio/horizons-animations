# Horizon Animation

Enhanced player animations for the [Create: Horizons](https://github.com/Hakuni-studio/create-horizons) modpack. Built on [Kelvin's Better Animations](https://github.com/Kelvin285/better-animations) by Kevin Merrill (Kelvin285).

## Requirements

- Minecraft **1.21.1**
- NeoForge **21.1.219+**
- [Player Animator](https://modrinth.com/mod/playeranimator) (KosmX)

## Development

```bash
./gradlew build          # compile
./gradlew runClient      # run in dev environment
```

Output JAR: `build/libs/horizonanimation-1.0.0.jar`

## Releases

Published to [GitHub Releases](https://github.com/Hakuni-studio/horizons-animations/releases) for use by the Create: Horizons modpack (packwiz).
